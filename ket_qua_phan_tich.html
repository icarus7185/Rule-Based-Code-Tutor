BƯỚC 2: KIỂM TRA LOGIC
[Dòng 9] Truy cập phần tử mảng với chỉ số cố định.
💡 Gợi ý từ AI:

Dòng 9 của bạn sai logic vì bạn đang dùng mảng char tĩnh (char name[100]) để lưu trữ tên, nhưng sau đó bạn không kiểm tra liệu có nhập giá trị cho biến này hay không. Trong C++, nếu không gán giá trị cho một biến, nó sẽ giữ giá trị mặc định là 0 hoặc một giá trị khác tùy thuộc vào loại biến.

Để sửa lỗi này, bạn cần đảm bảo rằng tên được nhập vào trước khi sử dụng:

#include <iostream>

int main() {
    char name[100];

    // Nhập tên
    std::cout << "Tên của bạn là: ";
    for (int i = 0; i < 99; ++i) {
        char c;
        std::cin >> c;
        name[i] = c;
    }
    name[99] = '\0';  // Đảm bảo kết thúc bởi ký tự null

    return 0;
}
